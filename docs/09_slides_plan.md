**포함 내용**
- 개인 투자자(개미)의 공통 패턴

  - 매매 이유를 기록하지 않음

**시각 요소**

- 구현 범위 요약
  - 국내·해외 통합 포트폴리오
  - 매매일지 (이유 태그·심리·메모)
  - AI 성향 진단·코칭·종목 분석
- 기대 효과: 기록 습관 → 패턴 인식 → 투자 개선

### S4 — 기술 스택 & 아키텍처 (4:00, ~1분 30초)

**보고서 항목**: ④ 기술 스택 (전체 아키텍처)

**레이아웃**: 아키텍처 다이어그램 + 기술 스택 테이블

**포함 내용**

**기술 스택 요약**
| 구분 | 기술 |
|------|------|
| 프론트엔드 | Next.js 14 App Router · TypeScript · Tailwind CSS v4 · Recharts |
| 백엔드 | Next.js API Routes · NextAuth.js v5 · Prisma ORM |

**아키텍처 다이어그램 구성**
```
[사용자 브라우저]

[Next.js 14 App Router]
  ├── /app/...      ← 화면 (Soo 담당)
  └── /app/api/...  ← API Routes (우철 담당)
        ├── KIS Open API   → 국내 주가
        ├── yahoo-finance2 → 해외 주가
        ├── Claude API     → AI 분석·Vision
        └── Supabase DB    → PostgreSQL
```

**AI 활용 포인트 하이라이트** (강조 표시)

**팀 역할 분담**

## 4. 슬라이드 기술 구현 방향 (실제 구현)

**방식**: Next.js App Router (`/app/slides/page.tsx`) — 단일 파일, 순수 Tailwind + inline style

**구조**
- 테마 토큰(`LIGHT`/`DARK`) 객체로 라이트/다크 모드 분리
- 각 슬라이드는 독립 함수 컴포넌트 (`Slide1`, `SlideBackground`, …)
- `SLIDE_LIST` 배열로 순서 관리, `current` state로 렌더링
- 인쇄 시 `print-container` div에 전체 슬라이드 렌더링 (PDF 출력용)

**디자인 토큰 (slides 전용)**
```
Primary:  #05C072  primarySoft / primaryDark / primaryMid
Text:     #1A221A (light) / #DCE8DC (dark)
Card:     #FFFFFF (light) / #1D2720 (dark)
Negative: #F04452
Warning:  #FF7B00
Blue:     #4285F4
```

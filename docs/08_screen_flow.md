```

│  로그인   │───→│ 회원가입  │───→│  온보딩   │───→│    대시보드 (홈)     │
│ /login   │←───│/register │    │/onboarding│    │        /           │

                                                         │
        ┌──────────────┬─────────────┬──────────────┬────┴──────┬──────────────┐
        │              │             │              │           │              │

  │ 계좌 관리  │ │ 매매일지  │ │  종목 분석   │ │ 투자 성향  │ │ 회원정보  │ │  관리자       │
```

## 1. 로그인 `/login`

```
┌─────────────────────────────────┐
│        🐜 버텨일지               │
│   나만의 투자 기록을 시작하세요    │
│                                 │
│  이메일   [________________]    │
│  비밀번호 [________________]    │
│                                 │
│  [      로그인      ]           │
│  ──────── 또는 ────────         │
│  [ Google로 로그인  ]           │
│  [ 카카오로 로그인   ]           │
│                                 │
│  아직 계정이 없으신가요? 회원가입  │
└─────────────────────────────────┘

→ 로그인 성공 + 온보딩 미완료 → /onboarding
→ 로그인 성공 + 온보딩 완료   → / (대시보드)
→ 이미 로그인 상태           → / (자동 이동)
→ 회원가입 링크 클릭         → /register
```

## 2. 회원가입 `/register`

### Step 1 — 정보 입력

```
┌─────────────────────────────────┐
│  🐜 버텨일지                     │
│  회원가입 · 투자 기록을 시작해보세요│
│                                 │
│  이름         [________________]│
│  이메일       [________________]│
│  비밀번호     [________________]│
│  비밀번호 확인 [________________]│
│                                 │
│  [     가입하기     ]           │
│                                 │
│  이미 계정이 있으신가요? 로그인   │
└─────────────────────────────────┘

유효성 검사:
  - 비밀번호 8자 미만 → "비밀번호는 8자 이상이어야 해요."
  - 비밀번호 불일치   → "비밀번호가 일치하지 않아요."
  - 이메일 중복      → "이미 사용 중인 이메일이에요."
```

### Step 2 — 가입 완료

```
┌─────────────────────────────────┐
│           ✅ 가입 완료!          │
│                                 │
│  버텨일지에 오신 걸 환영해요.     │
│  나만의 투자 기록을 시작해볼까요?  │
│                                 │
│  [    시작하기 →    ]           │
└─────────────────────────────────┘

→ 시작하기 클릭 → 자동 로그인 → /onboarding
```

## 3. 온보딩 `/onboarding` (최초 1회)

가입 후 빈 화면 이탈 방지. 첫 데이터를 자연스럽게 등록하도록 유도.

### Step 1/2 — 계좌 & 종목 등록

```
┌─────────────────────────────────────────────┐
│  Step 1/2  계좌 & 종목 등록                   │
│  보유 중인 계좌와 종목을 등록하세요.            │
│                                             │
│  ── 계좌 1 ──────────────────────────────   │
│  증권사  [ 키움증권 ▼ ]                      │
│  예수금(원)  [ 선택사항 ]  예수금($) [ 선택 ]  │
│                                             │
│  종목 검색  [ 삼성전자_______ ] → 자동완성     │
│  평단가    [ 72,000 ]  수량 [ 50 ]           │
│  내 섹터   [ 선택사항 ]  태그 [ 선택사항 ]     │
│  [+ 종목 추가]                              │
│                                             │
│  ✓ 삼성전자  72,000원  50주  [삭제]          │
│  ✓ NVIDIA   $850     10주   [삭제]          │
│                                             │
│  [+ 계좌 추가]                              │
│                                             │
│  [건너뛰기]              [다음 →]            │
└─────────────────────────────────────────────┘

- 계좌 여러 개 추가 가능
- 예수금은 선택 (빈칸이면 0)
- 종목 검색 시 키보드 방향키(↑↓)로 후보 이동, Enter 선택
- 종목 등록 시 기본섹터(sectorAuto) 자동 조회 (KIS/Yahoo)
```

### Step 2/2 — 첫 매매 기록

```
┌─────────────────────────────────────────────┐
│  Step 2/2  첫 매매 기록                       │
│  최근 매매를 하나만 기록해보세요.               │
│                                             │
│  계좌 선택  [ 키움증권 ▼ ]                    │
│  매수 ○ / 매도 ○                            │
│  종목 검색  [________________]               │
│  가격      [________]  수량 [______]         │
│                                             │
│  이유 태그 (선택):                            │
│  [저평가] [분할매수] [실적호조] [기술적분석] ...│
│                                             │
│  [건너뛰기]              [완료 →]            │
└─────────────────────────────────────────────┘

→ 완료 또는 건너뛰기 → / (대시보드)
→ 이후 재방문 없음 (User.onboardingDone = true)
```

## 5. 계좌 관리 `/accounts`

등록된 투자 계좌 목록 조회 + 계좌 추가/삭제.

```
┌─────────────────────────────────────────────┐
│  ← 계좌 관리              [+ 계좌 추가]      │
│                                             │
│  ┌─────────────────────────────────────┐   │
│  │ 💳 키움증권                          │   │
│  │ 5종목 · 예수금 ₩1,200,000           │   │
│  │ 평가금 ₩8,500,000  매수금 ₩8,100,000│   │
│  │ +4.9%                    [수정][삭제]│   │
│  └─────────────────────────────────────┘   │
│  → 카드 클릭 시 /accounts/[id] 이동         │
│                                             │
│  ┌─────────────────────────────────────┐   │
│  │ 💳 미래에셋증권                      │   │
│  │ 3종목 · 예수금 $500                  │   │
│  │ ...                                 │   │
│  └─────────────────────────────────────┘   │
└─────────────────────────────────────────────┘

[+ 계좌 추가] → 바텀시트 모달 (증권사 선택 + 예수금 입력)
[삭제] → ConfirmDialog 확인 모달
```

## 7. 매매일지 `/trades`

전체 매매 기록 조회, 등록, 수정, 삭제. PC 테이블 / 모바일 리스트 반응형.

```
┌─────────────────────────────────────────────┐
│  ← 매매일지                                  │
│                                             │
│  ── 요약 칩 ────────────────────────────    │
│  총 23건 · 매수 ₩5,200,000 · 매도 ₩1,800,000│
│                                             │
│  ── 필터 ───────────────────────────────    │
│  날짜: [04-01] ~ [04-07]  [1주|1개월|3개월]  │
│  계좌: [전체 ▼]  종목: [검색...]             │
│  [매수|매도|전체]  [국내|해외|전체]            │
│                                             │
│  ── 캘린더 뷰 (토글) ──────────────────     │
│  날짜별 매매 건수 히트맵                      │
│                                             │
│  ── PC: 테이블 ─────────────────────────    │
│  일자     구분  종목      단가     수량  금액  │
│  04-06   매수  삼성전자  72,000   50  3,600,000│
│  04-05   매수  NVIDIA   $850    10  $8,500   │
│  → 행 클릭 시 매매 상세 바텀시트              │
│                                             │
│  ── 모바일: 리스트 카드 ────────────────     │
│  ┌ 매수  삼성전자  ₩3,600,000 ────────┐    │
│  │ 04-06 · ₩72,000 · 50주 · 키움증권  │    │
│  │ [저평가] [분할매수]                 │    │
│  └────────────────────────────────────┘    │
│                                             │
│  (FAB) [+ 매매 등록]                        │
└─────────────────────────────────────────────┘
```

### 매매 등록 바텀시트

```
┌─────────────────────────────────────────────┐
│  매매 등록                                   │
│                                             │
│  [필수]                                     │
│  계좌    [ 키움증권 ▼ ]                      │

│  수량    [ 50 ]                             │
│                                             │
│  [선택]                                     │
│  이유 태그:                                  │
│  [저평가] [분할매수] [실적호조] [테마·트렌드]   │
│  [기술적분석] [신규진입] [배당목적] ...         │
│                                             │
│  심리 상태:                                  │
│  [확신] [불안] [FOMO] [손절] [기계적]         │

│  메모    [________________]                 │
│                                             │
│  [      등록하기      ]                     │

- 매수 시 예수금 부족 → 경고 모달 (차단 아님, 강행 가능)

```

## 9. 투자 성향 `/personality`

> 경로 변경: `/analysis/personality` → `/personality` (단일 페이지에서 진단·통계·코칭 통합)

**히어로 카드 — 나의 투자자 유형 (3단계 자동 분기)**

```
┌─────────────────────────────────────────────┐
│  ← 투자 성향                                  │
│                                             │
│  ── 잠금 (매매 0건 + 보유 종목 0건) ────     │
│  🔒 투자 성향 분석이 잠겨있어요               │
│  매매 3건 이상 또는 보유 종목 1개 이상 필요    │
│  [매매 기록하러 가기]                         │
```

## 9-1. 스크린샷 종목 등록 (계좌 상세 → 종목 캡처 불러오기)

```

        ↓
┌─────────────────────────────────────────────┐
│  계좌 캡처 불러오기                           │
```

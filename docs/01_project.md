# 🚀 AI 투자 관리 프로그램 — 설계 문서 v3.5
> 최종 업데이트: 2026-04-10 | 멀티유저 소규모 (~50명) · 2인 팀 · Claude Code 개발

---

## 1. 프로젝트 개요

개인의 국내/해외 주식 포트폴리오와 예수금을 통합 관리하고,
**Claude API**를 통해 종목 분석 인사이트 및 투자성향 진단·코칭 리포트를 제공하는
**가계부형 수기 투자 관리 웹 서비스**.

| 항목 | 내용 |
|------|------|
| 서비스 규모 | 소규모 (지인/팀 내부용, ~50명) |
| 인증 방식 | 이메일+비밀번호 + 소셜 로그인 (Google / Kakao) |
| 데이터 격리 | 단일 DB, `userId` 컬럼 행 단위 격리 |
| 실행 환경 | 로컬 실행 (`npm run dev`) — 배포 없음 · 팀 내부 로컬에서 운영 (DB만 Supabase 클라우드) |
| 타겟 사용자 | 초보~중급 투자자 — 진입 장벽 최소화 |
| 반응형 지원 | 모바일 + 데스크톱 (Tailwind 브레이크포인트) · 다크모드 토글 |
| 개발 방식 | 2인 팀 · Claude Code 활용 |

### 핵심 철학

> **"수기 입력의 마찰 자체가 제품 가치"** — 자동화보다 기록하는 행위 자체가 투자 반성의 계기가 됨

### 핵심 차별점

기존 앱(더리치, 도미노 등) 대비 **이 서비스만의 차별점**:

```
① 국내·해외 종목 구분 없이 통합 포트폴리오 관리
② 매매일지 — 이유 태그 + 심리 상태 + 자유 메모 (가계부 방식)
③ AI 투자성향 진단 — 매매 패턴으로 투자자 유형 분류 + 통계
④ AI 코칭 리포트 — 잘하는 점 / 반복 실수 / 개선 목표 제시 (히스토리 누적)
⑤ AI 종목 분석 — SWOT · 적정가 · 최근 호재/악재 요약
⑥ 스크린샷 종목 등록 — 증권사 앱 캡처 이미지로 보유 종목 일괄 등록
```

## 2. 기술 스택

| 구분 | 기술 | 비고 |
|------|------|------|
| 프론트엔드 | **Next.js 16.2** (App Router, Turbopack) | React 19 · TypeScript strict · Tailwind CSS v4 · Recharts 3 |
| 백엔드 API | Next.js API Routes | 별도 서버 없음 |
| 인증 | **NextAuth.js v5** (beta.30) | JWT · Credentials + Google + Kakao |
| 비밀번호 | **bcrypt** (saltRounds: 12) | 평문 저장 금지 |
| 데이터베이스 | PostgreSQL + **Prisma ORM** v7 | **Supabase 무료 티어** (클라우드 공유 DB) · 2인 팀 공동 접속 |
| 국내 종목 검색 | **공공데이터포털 KRX** + DB 저장 (`stock_master`) | 전체 목록 1회 저장 후 자체 검색 |
| 국내 주가 조회 | **한국투자증권 Open API (KIS)** | 개발자 계정 1개 · 사용자 한투 계좌 불필요 |
| 국내 섹터 조회 | **KIS Open API** (`bstp_kor_isnm`) | 종목 등록 시 자동 조회 |
| 해외 데이터 | **yahoo-finance2** | API 키 불필요 · 검색·주가·차트·섹터 지원 |
| 해외 섹터 조회 | **yahoo-finance2** (`quoteSummary` assetProfile) | 종목 등록 시 자동 조회 |
| AI 분석 | **Claude API** (`claude-sonnet-4-6`) | 기업 요약 · SWOT · 호재/악재 · 성향 진단 · 코칭 · 스크린샷 OCR |
| 다크모드 | **next-themes** | 라이트/다크 토글 지원 |
| 차트/시각화 | **Recharts 3** | 자산 추이 · 섹터 도넛 · MDD · 매매 캘린더 |
| 실행 환경 | **로컬 실행** (`npm run dev`) | 배포 없음 · 팀 내부 로컬에서 운영 · DB는 Supabase 클라우드 |

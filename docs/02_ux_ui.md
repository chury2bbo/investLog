# 🚀 AI 투자 관리 프로그램 — 설계 문서
> 최종 업데이트: 2026-04-20 | 멀티유저 소규모 (~50명) · 2인 팀 · Claude Code 개발

## 3. UX 설계 원칙

### 3-1. 수기 입력 설계 철학

이 서비스는 **가계부처럼 직접 기록하는 투자 관리 도구**입니다.
자동화보다 수기 입력을 선택한 이유는 명확합니다.

- 매매 이유 태그를 고르는 순간 "이게 FOMO인가, 진짜 확신인가"를 한 번 더 생각하게 됨
- 입력하는 행위 자체가 투자 반성의 계기가 됨
- 이 데이터가 쌓여서 투자성향 분석의 원천이 됨 — 자동화하면 이 과정이 사라짐

단, 입력 마찰을 최소화하는 것이 핵심입니다.

**필수 vs 선택 3단계 분리**

| 구분 | 항목 | 처리 |
|------|------|------|
| 🔴 필수 | 종목 / 매수·매도 / 가격 / 수량 | 없으면 저장 불가 |
| 🟡 선택 | 이유 태그 / 심리 상태 / 메모 | 나중에 추가 가능 |
| ⚪ 선택 | 섹터 / 태그 | 언제든 수정 가능 |

**이전 거래 복사 기능**
같은 종목을 분할매수하는 경우 직전 거래를 불러와 수정만 하면 입력 시간 절반 단축.

```
[이전 거래 불러오기]
삼성전자  매수  72,000원  50주 → 가격·수량만 수정
```

**미완성 태그 알림**
매매 직후 바쁠 때 필수 항목만 저장 가능. 이유 태그 없는 기록엔 알림 유도.

```
📝 삼성전자 매수 기록에 이유 태그가 없어요.  [지금 추가하기]
```

### 3-2. 온보딩 플로우 (가입 직후 1회)

빈 화면 이탈 방지. 첫 데이터 입력까지 자연스럽게 유도.

```
가입 완료
    ↓
Step 1 / 2 — 계좌 & 종목 등록
  ┌──────────────────────────────────────┐
  │ 계좌 1                               │
  │ 계좌명  [ 키움증권 (국내)    ]        │
  │ 예수금  [ 선택사항     ] KRW ← 선택  │
  │         💡 나중에 계좌 상세에서 입력  │
  │                                      │
  │ 종목명 검색 [ 삼성전자 ] → 005930    │
  │ 평단가 [ 72,000 ]  수량 [ 50 ]  [추가]│
  │ 내 섹터 [ 선택사항 ]  태그 [ 선택사항]│
  │                                      │
  │ ✓ 삼성전자  72,000원  50주  [삭제]   │
  │ [+ 종목 추가]                        │
  └──────────────────────────────────────┘
  [+ 계좌 추가]   ← 계좌 수 제한 없음
  [건너뛰기]  [다음 →]
    ↓
Step 2 / 2 — 첫 매매 기록
  매수/매도 간단 등록 + 이유 태그 소개
  [건너뛰기]  [완료 →]
    ↓
대시보드
```

- 예수금은 선택 입력 (빈칸이면 0으로 저장)
- `User.onboardingDone` 플래그로 재진입 시 스킵
- 소셜 로그인(Google/Kakao) 콜백도 온보딩으로 리다이렉트 (구현 완료)
- 종목 등록 시 `sectorAuto` 자동 조회 (KIS/Yahoo → DB 저장, 구현 완료)
- **스크린샷 종목 등록**: 증권사 앱 잔고 화면 캡처 → Claude Vision으로 종목명·평단가·수량 자동 추출 (구현 완료)

### 3-3. 종목 검색 — 종목명 우선

초보는 티커를 모르므로 종목명으로 검색하면 티커 자동 매핑.

```
[ 삼성전자 ] → 삼성전자  005930  KOSPI  반도체
[ NVID     ] → NVIDIA Corp  NVDA  NASDAQ  Technology
```

| 구분 | 검색 방식 |
|------|-----------|
| 국내 | DB 자체 검색 (KRX 목록 사전 저장, 빠름·API 호출 없음) |
| 해외 | yahoo-finance2 search() API 실시간 호출 |

**종목 검색 드롭다운 키보드 네비게이션** (구현 완료)
- 방향키(↑↓)로 후보 이동, Enter로 선택, Escape로 닫기
- 보유종목 등록 팝업·매매 등록 팝업 모두 동일 동작

### 3-4. Progressive Disclosure (단계별 기능 노출)

| 레벨 | 조건 | 노출 기능 |
|------|------|-----------|
| 기본 | 항상 | 현재가·수익률·보유 수량·평단가 |
| Level 1 진단 | 보유 종목 1개 이상 | 보유 구성 기반 간이 투자성향 (유형명 + 1문장) |
| 데이터 패턴 | 매매 3건 이상 | 매매 이유/감정/섹터/보유기간 차트 |
| Level 2 진단 | 매매 5건 이상 | 정밀 투자성향 (유형명 + 강점/약점 + 통계 3칸) |
| AI 코칭 | 매매 10건 이상 | 잘하는 점·반복 실수·개선 목표 코칭 리포트 |

> 모든 진단 데이터는 **최근 6개월 매매**를 기준으로 집계 — 현재 성향에 가중치 부여 + 비용 통제

### 3-5. 용어 툴팁

| 용어 | 설명 |
|------|------|
| Forward PER | 올해 예상 실적 기준 주가 수준. 낮을수록 저평가 가능성 |
| PBR | 순자산 대비 주가 수준. 1 미만이면 장부가보다 싸게 거래 중 |
| MDD | 고점 대비 최대 하락폭. -30%면 최악의 시기에 30% 손실 가능 |
| 예수금 | 증권 계좌에 있는 현금 잔고 |

### 3-6. 로딩 UX — Skeleton 기반 점진적 로딩 (구현 완료)

데이터 로딩 중 빈 화면 대신 **콘텐츠 형태를 예측하는 Skeleton UI**로 체감 속도 향상.

**적용 원칙**
```
① 고정 요소 즉시 표시 — 헤더, 인사말, 네비게이션, 다크모드 토글
② 데이터 의존 영역 → Skeleton 플레이스홀더
③ 데이터 도착 → fadeIn 애니메이션으로 자연스럽게 전환
```

**반응형 Skeleton 분기** (모바일/데스크톱 별도 레이아웃 — 실제 렌더와 1:1 일치)
```
대시보드:  히어로 카드 + 미니카드 4개 (모바일 2x2 / PC 4컬럼) + 요약 지표 4칸 + 자산배분 + 계좌 카드
계좌 관리: 모바일(1열 카드) / 데스크톱(2열 + 사이드바 차트)
계좌 상세: 그라디언트 히어로 + 보유종목 3행 + 섹터 차트
매매일지:  모바일(상단바 + 요약칩 + 리스트 6행) / 데스크톱(헤더 액션 + 필터 + 요약칩 + 7컬럼 테이블)
투자 성향: 히어로(통계 3칸 포함) + 데이터 패턴 + 코칭 카드 (실제 구조와 일치)
```

**Skeleton 컴포넌트 사양**
- Shimmer 애니메이션 (CSS gradient, 1.5s 반복)
- 라이트: `--color-g100` / 다크: `--color-border` 기반
- `className` props로 크기·모양 커스터마이징

### 3-7. 팝업 UI 통일 패턴 (구현 완료)

모든 팝업·모달을 **BottomSheet + ConfirmDialog** 패턴으로 일관성 있게 통일.

| 용도 | 컴포넌트 | 적용 화면 |
|------|----------|-----------|
| 데이터 입력·편집 | BottomSheet (하단 슬라이드업) | 매매 등록, 종목 등록, 예수금 입출금, 섹터 편집, 스크린샷 종목 등록, AI 코칭 전체 히스토리 |
| 삭제·위험 확인 | ConfirmDialog (중앙 모달) | 계좌 삭제, 매매 삭제, 보유종목 삭제, 회원탈퇴 |
| 알림 | Toast (상단 슬라이드다운) | 저장 완료, 중복 종목, 예수금 부족 경고 |

### 3-8. 매매 상세 바텀시트 (구현 완료)

매매일지 리스트에서 항목 클릭 시 **매매 상세 바텀시트** 표시.

```
┌──────────────────────────────────┐
│ 삼성전자 매수                      │
│ 2026-04-06  72,000원  50주         │
│────────────────────────────────────│
│ 이유 태그:  저평가 / 분할매수       │
│ 심리 상태:  확신                    │
│ 메모:       1분기 실적 기대         │
│────────────────────────────────────│
│ [수정]  [삭제]                     │
└──────────────────────────────────┘
```

- 인라인 수정 기능 (가격·수량·태그·메모 직접 편집)
- 삭제 시 ConfirmDialog로 이중 확인

## 4. UI 가이드라인

### 4-1. 디자인 컨셉

**Modern Fintech UI + Human-Centered Minimal Design**
토스 스타일 — 친근하고 간결하되 명확하게. 복잡한 수치도 읽기 쉽게.

### 4-2. 컬러 시스템

| 역할 | 컬러 | 용도 |
|------|------|------|
| Primary | `#05C072` 그린 | 버튼·포인트·수익 표시 |
| Primary Mid | `#03A862` 그린 미드 | 그라디언트·차트 보조색 |
| Positive | `#05C072` | 수익·매수 표시 |
| Negative | `#F04452` | 손실·매도 표시 |

### 4-3. 레이아웃

**PC (768px 이상)**
- 왼쪽 아이콘 전용 사이드바 64px 고정
  - 아이콘만 표시, hover 시 오른쪽에 툴팁 등장
  - 활성 탭 왼쪽에 그린 인디케이터 바 + 아이콘 색상 강조 (배경 박스 없음, 모바일과 동일 룩)
  - 하단에 다크모드 토글 + 사용자 아바타
- 메인 컨텐츠 최대 720px 중앙 정렬

**모바일 (768px 미만)**
- 하단 바텀 네비게이션 5탭
- 매매 등록 FAB 버튼 (우측 하단 그린 플로팅 버튼)
- 우측 상단 다크모드 토글
- 계좌 상세에서도 모바일 다크모드 토글 접근 가능 (구현 완료)
- 대시보드 미니카드/요약 지표 4칸은 **모바일 2x2 그리드**로 노출 (4컬럼은 데스크톱 전용)
- 매매일지 SummaryChips는 모바일에서 좌우 라벨/금액 + 가로 구분선 스택 레이아웃

### 4-4. 컴포넌트 시스템 (구현 완료 — 17종)

| 컴포넌트 | 용도 | 비고 |
|----------|------|------|
| **Button** | 액션 버튼 | variant: primary(그린) / secondary(회색) / black |
| **Card** | 카드 컨테이너 | 16px 모서리, 라이트/다크 모드 대응, `onClick` prop 지원 |
| **Tag** | 분류 태그 | 배경색+텍스트색 props, 6px 모서리 |
| **PnlTag** | 수익/손실 태그 | 수익(그린)/손실(레드) 자동 색상 |
| **Input** | 입력 필드 | 언더라인 스타일, 라벨 포함 |
| **Select** | 드롭다운 선택 | 증권사·계좌 선택 등 |
| **Divider** | 구분선 | 1px 구분선 |
| **Tabs** | 탭 전환 | variant: segment(세그먼트 버튼) / chip(칩 형태), 제네릭 키 타입 지원 |
| **BottomSheet** | 바텀시트 모달 | 하단에서 올라오는 방식, 핸들 바 포함, `titleRight` prop 지원 |
| **Toast** | 알림 메시지 | 상단 슬라이드다운, 자동 사라짐 |
| **ConfirmDialog** | 확인 모달 | 삭제·위험 작업 이중 확인 |
| **LoadingSpinner** | 로딩 스피너 | 초기 로딩용 (Skeleton 도입 후 보조 역할) |
| **Skeleton** | 로딩 플레이스홀더 | Shimmer 애니메이션, 반응형 레이아웃별 적용 |
| **EmptyState** | 빈 상태 안내 | 데이터 없을 때 안내 문구+아이콘 |
| **SectionTitle** | 섹션 제목 | 15px bold |
| **ThemeToggle** | 다크모드 토글 | 라이트/다크 전환 |
| **index.ts** | Barrel Export | 전체 컴포넌트 통합 import 지원 |

### 4-5. 바텀시트 모달 목록

| 모달 | 트리거 | 주요 입력 |
|------|--------|-----------|
| 매매 등록 | FAB / [+ 매매 등록] 버튼 | 종목·가격·수량·이유태그·심리 |
| 매매 상세/수정 | 매매 리스트 항목 클릭 | 가격·수량·태그·메모 인라인 수정 |
| 예수금 부족 경고 | 매수 시 잔고 부족 | [등록] (강행) / [취소] |
| 섹터 편집 | 종목 카드 [편집] | 기본섹터(읽기전용)·내섹터 |
| 입금 등록 | [+ 입금] 버튼 | 통화·금액·메모 |
| 출금 등록 | [출금] 버튼 | 통화·금액·메모 |
| 계좌 추가 | [+ 계좌 추가] | 계좌명·예수금 |
| 보유종목 수정 | 종목 행 [수정] 버튼 | 평단가·수량 편집 |
| AI 종목 분석 | [분석 생성] 버튼 | — (결과 표시) |
| AI 성향 리포트 | [리포트 생성] 버튼 | — (결과 표시) |

### 4-6. 애니메이션 & 전환 효과

| 효과 | 적용 위치 | 사양 |
|------|-----------|------|
| fadeIn | 페이지 전환, 데이터 로딩 완료 | `fadeIn 0.4s ease-out` |
| Shimmer | Skeleton 컴포넌트 | CSS gradient `translateX`, 1.5s 반복 |
| 슬라이드업 | BottomSheet 등장 | 하단에서 올라오는 트랜지션 |
| 슬라이드다운 | Toast 알림 | 상단에서 내려오는 트랜지션, 3초 후 자동 사라짐 |

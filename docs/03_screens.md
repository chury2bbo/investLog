## 5. 핵심 화면 요구사항

### 📊 ① 통합 대시보드 `/` (구현 완료)
- 총 보유 자산 (KRW 환산, 그린 그라디언트 히어로 카드)
- 국내 평가금 / 해외 평가금 / 투자원금 / 예수금 **미니카드 4개** (모바일 2×2, PC 4컬럼)
- 실시간 환율 + [새로고침] + 다크모드 토글
- 요약 지표 4칸 (총 수익률 / 총 수익금 / 보유 종목 / 총 계좌) — 모바일 2×2, PC 4컬럼
  - **총 수익률 카드**: 클릭 시 BenchmarkSheet BottomSheet — KOSPI/S&P500/NASDAQ/BTC/금/달러/서울아파트와 YTD(1월 1일~현재) 수익률 양방향 바 차트 비교
  - **보유 종목 카드**: 보유 종목 1개 이상 시 클릭 가능 — 종목별 비중 BottomSheet 표시 (평가금액 기준 바 차트, 국내/해외 배지, 1위 그린 강조)
- 자산 배분 바 차트 + 범례 (국내주식 / 해외주식 / 원화예수금 / 달러예수금)
- 종목별 비중 도넛 차트 (비중 순 정렬)
- 총 자산 추이 차트 + 월별 자산 스냅샷 자동 적재
- 투자 성향 위젯 (마지막 진단 결과 + 진단 버튼 — `/personality`로 이동)
- 계좌 현황: 간략 카드 (증권사명 · 종목수 · 수익률) — 클릭 시 계좌 상세 이동
- 환율 + 현재가 병렬 조회 (Promise.all)
- Skeleton 로딩 UI (인사말·토글 즉시 표시, 데이터 영역은 Skeleton — 실제 그리드와 동일 구조)

### 💳 ② 계좌 관리 `/accounts` (구현 완료)
- 계좌 카드: 증권사명 · 종목수 · 수익률 (상단) + 예수금·평가금·매수금·합산 (중단) + [수정][삭제] (하단)
- 현재가 + 환율 실시간 조회, 원화 환산 통일
- [+ 계좌 추가] 버튼 → 계좌 추가 바텀시트
- 수정 바텀시트: 증권사 변경 · 메모 수정
- 삭제 확인 모달 (ConfirmDialog)
- 중복 증권사 체크 및 에러 표시
- Skeleton 로딩 UI: 모바일(1열) / 데스크톱(2열 + 사이드바 차트)

### 💳 ③ 계좌 상세 `/accounts/[id]` (구현 완료)

```
① 자산 요약 카드 (그린 그라디언트)
   합산(원화) 전체 금액 표시
   예수금·평가금·매수금·합산 4열 그리드 (원화/달러 행 분리)
   [+ 입금] [출금] 버튼

② 보유 종목 리스트 + [+ 종목 등록]
   종목명·현재가·수익률·평가금액 (수익 그린 / 손실 레드)
   평단가·평가금액
   기본섹터·내섹터 태그 + [편집] → 섹터 편집 바텀시트
   [수정] → 평단가·수량 인라인 편집 / [삭제] → ConfirmDialog 확인
   캡처 불러오기 기능

③ 매매 이력 (최근 5건)
   날짜·종목·구분·가격·수량
   [전체 매매일지 보기 →] → /trades?accountId=[id]

④ 섹터 분포 차트
   [기본 섹터] 탭 — sectorAuto 기준 (항상 표시)
   [내 섹터] 탭 — sectorManual 1개 이상 시에만 탭 노출
   평가금액 기준 비율 계산, 원화 환산 통일

⑤ Skeleton 로딩 UI
   그라디언트 히어로 즉시 표시 + 보유종목 3행 Skeleton + 섹터 차트 Skeleton
```

- 모바일 다크모드 토글 접근 가능

### 📝 ④ 매매일지 `/trades`

**PC (md 이상) — 테이블 뷰** (구현 완료)
- 필터 카드: 날짜 범위 + 빠른선택 + 계좌 + 종목 검색 (자동완성 드롭다운)
- 세그먼트: 매수/매도 · 국내/해외 토글
- 테이블 컬럼: 일자 · 구분 · 시장 · 종목 · 단가 · 수량 · 체결금액 · 이유태그
- 정렬: 일자 / 단가 / 체결금액 (클릭 토글)
- 페이지네이션 (20건)
- 매매 상세 바텀시트: 항목 클릭 → 상세 보기 + 인라인 수정 + 삭제
- 입력 검증: 가격·수량 0 이하 입력 방지

**모바일 (md 미만) — 리스트 뷰** (구현 완료)
- 상단 sticky 바: 타이틀 + 필터 토글(funnel 아이콘, 열림 시 그린 active) + 매수/매도 · 국내/해외 세그먼트
  - "전체" 텍스트 → 2×2 그리드 SVG 아이콘 (텍스트 절약, 토글 너비 확보)
  - "필터" 텍스트 → funnel SVG 아이콘 버튼 (열림/닫힘 상태 컬러 표시)
- 필터 패널 (토글): 날짜 · 계좌 · 종목 검색 · 태그 유무 (미입력 → 그리드 아이콘)
- 리스트 아이템: 2줄 구조 (뱃지+종목명+금액 / 날짜·단가·수량·계좌·태그)
- **무한 스크롤**: 페이지 하단 도달 시 다음 페이지 자동 로딩 (페이지네이션 버튼 대신)
- FAB 버튼 (매매 등록)
- Skeleton 로딩 UI: 모바일(리스트 5행) / 데스크톱(7열 테이블)

**캘린더 뷰** (구현 완료)
- 리스트/캘린더 토글 버튼으로 전환
- 월간 요약: `N월 — 매수 N회 / 매도 N회 / 순매수 ±₩N`
- 날짜 dot 인디케이터: 매수(초록) · 매도(주황) · 일별 메모(파란) dot 표시
- 날짜 클릭 → 하단에 해당 일자 매매 목록 + **일별 메모 입력 영역** 표시
  - textarea (언더라인 스타일) — 시장 흐름·감정·투자 일지 자유 기록
  - 저장 버튼 (`Button black/sm`) — API: `PUT /api/trades/memo`
  - 날짜 이동 시 해당 날짜 메모 자동 로드 — API: `GET /api/trades/memo?date=YYYY-MM-DD`
  - 월 이동 시 해당 월 메모 있는 날짜 목록 일괄 조회 — `GET /api/trades/memo?month=YYYY-MM`
- 저장 실패 시 콘솔 에러 로깅 (silent fail 방지)

**요약 칩 바 (공용)**: 건수 · 매수 합계(₩/$ 분리) · 매도 합계(₩/$ 분리) · 수익률

**매매 등록 바텀시트 — 필수/선택 분리**
```
[필수] 계좌 선택 / 매매 날짜 / 매수·매도 토글
       종목 검색 (자동완성) / 가격 (현재가 자동조회) / 수량
───────────────────────────────
[선택] 이유 태그 (복수 선택, 툴팁 설명)
       심리 상태 (확신·불안·FOMO·손절·기계적)
       메모 (자유 텍스트)
```

- 매수 시 예수금 부족 → 확인 모달 ([등록] 강행 / [취소])
- 매도 시 미보유/수량 부족 → 토스트 경고, 차단

**이유 태그 목록**

| 매수 | 매도 |
|------|------|
| 실적호조 / 기술적분석 / 저평가 / 테마·트렌드 | 목표가달성 / 손절 / 고평가판단 / 실적악화 |
| 분할매수 / 신규진입 / 추가매수 / 배당목적 | 리스크헤지 / 포트리밸런싱 / 현금필요 / 테마종료 |
| 포트리밸런싱 / 지인추천 / 뉴스·공시 | 추세이탈 / 장기미보유 |

**예수금 처리 로직**

| 상황 | 처리 |
|------|------|
| 온보딩 종목 등록 | 예수금 무시 (holdings만 생성) |
| 매매일지 매수 | 예수금 차감 — 부족 시 확인 모달 (차단 아님) |
| 매매일지 매도 | 예수금 자동 증가 |
| 직접 관리 | 계좌 상세 > 예수금 관리 |

```
⑤ AI 종목 분석 리포트 [분석 생성]
   적정 매수·매도가 / SWOT / BUY·HOLD·SELL
   최근 주요 이슈 (호재/악재 라벨 분리 표시)
   분석 날짜 표기: "Claude AI · YYYY-MM-DD 분석 (캐시)" — 신뢰도 확인용
   (당일 캐시 — 같은 날 동일 티커는 1회만 호출, 사용자당 10회/일 제한)
```

### 🧠 ⑥ 투자 성향 `/personality`

> 경로가 `/analysis/personality` → `/personality`로 이동했고, 단일 페이지에서 진단·통계·코칭을 모두 제공합니다.

**섹션 1 — 나의 투자자 유형 (히어로 카드)**

| 상태 | 활성 조건 | 카드 내용 |
|------|-----------|-----------|
| Lock | 매매 0건 + 보유 종목 0건 | "투자 성향 분석이 잠겨있어요" + 매매일지 이동 버튼 |
| Level 1 | 보유 종목 1개+ (매매 5건 미만) | 유형명 + 1문장 요약 + "보유 종목 기반" 라벨 + AI 진단 버튼 |
| Level 2 | 매매 5건+ (최근 6개월) | 유형명 + 강점/약점 2문장 + 통계 3칸 (승률/평균보유/손절비율) |

- 1회/일 제한 통합 카운터 (Level 1 본 다음 매매 추가하면 다음날 Level 2)
- 마지막 결과는 `personality_result`에 저장 → 페이지 진입 시 즉시 표시 (`?last=true`)
- 히어로 하단에 진단 일자 표기 ("4월 10일 진단")

**섹션 2 — 데이터로 보는 내 패턴 (매매 3건 이상에서만)**

- 탭: 매매 이유 / 감정 / 섹터 / 보유기간
- 매매 이유 탭 안에 "태그별 거래 건수" 토글 (접기/펼치기)
- 매매 3건 미만이면 통째 잠금 카드 + 매매일지 이동 버튼

**섹션 3 — AI 코칭 (매매 10건 이상)**

- 잘하는 점 / 반복 실수 / 이번 달 개선 목표 카드
- 호출당 새 row가 `coaching_history`에 누적
- 메인에는 **최근 5개**만 노출, 그 이상은 "전체 히스토리 보기" → BottomSheet 모달
- 페이지 진입 시 **최신 1개는 자동 펼침**
- 사용자당 3회/일 제한, 최근 6개월 매매 10건 이상 필요

## 6. 섹터 기능 설계

### 6-1. 개념 정의

| 필드 | 출처 | 비고 |
|------|------|------|
| `sectorAuto` | 종목 등록/매매 등록 시 자동 조회 (국내→KIS, 해외→Yahoo) | 수동 새로고침 가능 |
| `sectorManual` | 사용자 직접 입력 | null이면 sectorAuto 폴백 |

```
실효 섹터 = sectorManual ?? sectorAuto ?? "기타"
```

### 6-2. 섹터 자동 조회

| 구분 | API | 응답 필드 |
|------|-----|----------|
| 국내 (6자리 숫자 티커) | KIS `inquire-price` | `bstp_kor_isnm` (업종 한글명) |
| 해외 (영문 티커) | Yahoo `quoteSummary` | `assetProfile.sector` |

자동 조회 시점: 종목 등록(POST /api/holdings), 매매 등록(POST /api/trades) — 신규 종목이거나 sectorAuto가 없는 경우에만 조회

### 6-3. 섹터 등록 진입점

**① 종목 추가 시 (온보딩 / 계좌상세 종목등록)**
```
종목명  [ 삼성전자   ]
평단가  [ 72,000    ]  수량   [ 50  ]
내 섹터 [ 선택사항   ]  ← 직접 입력 (예: "AI 반도체")
💡 기본 섹터는 자동으로 가져와요
```

**② 계좌 상세 인라인 편집**
```
종목 행에서 [편집] 클릭 → 섹터 편집 바텀시트
  기본 섹터: 전기·전자 (읽기 전용)
  내 섹터:   [ AI 반도체      ]
  [저장]
```

### 6-4. 계좌 상세 섹터 탭 조건

```
[기본 섹터] 탭 — sectorAuto 기준, 항상 노출
[내 섹터] 탭  — sectorManual 1개 이상 설정 시에만 탭 노출
               미설정 종목은 sectorAuto → "기타" 순으로 폴백
```

### 6-5. 섹터 분포 계산

- 평가금액 기준 (현재가 × 수량)
- 해외 종목은 실시간 환율로 원화 환산 후 비율 계산
